# ShineRoster

مشروع HTML وCSS وPHP بأسلوب OOP، مع MySQL/MariaDB، دون JavaScript أو أطر عمل. هذه نسخة منظّمة ومختبرة من الصفحات الموجودة للزبون ومقدم الخدمة. واجهة الأدمن مؤجلة وتبقى صفحة محمية بحالة 503.

## التشغيل

1. احتفظ بنسخة احتياطية من مشروعك وقاعدتك. فك النسخة في مجلد نظيف باسم `ShineRoster` داخل `htdocs`.
2. شغّل Apache وMySQL في XAMPP. المتطلبات: PHP 8.1+ مع `pdo_mysql` و`mbstring`، وMySQL 8.0.16+ أو MariaDB 10.4+.
3. **قاعدة موجودة:** التنظيف لا يحتاج تغيير مخططها أو إعادة استيراد البيانات. إذا كان جدولا `auth_limits` و`contact_messages` غير موجودين، استخدم `database/upgrade_security.sql`؛ يمكن تكراره ولا يحذف البيانات.
4. **قاعدة جديدة:** استورد ملفاً واحداً فقط: `database/shineroster.sql` للتركيب النظيف، أو `database/shineroster_with_demo.sql` لبيانات التجربة. لا تستورد ملف التركيب الكامل فوق قاعدة موجودة.
5. افتح `http://localhost/ShineRoster/` أو المسار الموافق لمجلدك.

الاتصال الافتراضي: `localhost`، قاعدة `shineroster`، المستخدم `root` وكلمة مرور فارغة. الإعدادات في `classes/Database.php`، ويمكن تجاوزها بمتغيرات البيئة `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`. إذا غيّرت اسم القاعدة، طابقه مع ملف SQL.

أبقِ ملفات `.htaccess` وتأكد أن Apache يسمح بتطبيقها؛ فهي تحمي المجلدات الداخلية وملفات SQL. للتطوير بخادم PHP المدمج، شغّل الأمر التالي من مجلد المشروع:

```bash
php -S 127.0.0.1:8000 router.php
```

## حسابات التجربة

- مقدم الخدمة: `provider1@shineroster.test`
- الزبون: `customer1@shineroster.test`
- كلمة المرور لجميع الحسابات التجريبية: `ShineDemo!2026`

هذه الحسابات موجودة في ملف البيانات التجريبية فقط. لا تستخدمها عند النشر؛ استخدم HTTPS ومستخدم قاعدة بيانات مخصصاً.

## تنظيم الكود

- `classes/`: منطق العمل والتعامل مع قاعدة البيانات.
- `includes/init.php`: تهيئة الاتصال والجلسة والحماية وتحميل الكلاسات والمساعدات المشتركة.
- `includes/catalog-header.php` و`catalog-footer.php`: الهيدر والفوتر المشترك لسبع صفحات عامة وصفحات الزبون.
- `includes/header.php` و`sidebar.php` و`footer.php`: الأجزاء المشتركة لمقدم الخدمة.
- `provider/`: صفحات مقدم الخدمة؛ ملفات PHP في الجذر تحتوي الصفحات العامة وصفحات الزبون.
- `css/`: التنسيقات المشتركة وتنسيقات الصفحات.
- `database/`: ملفات التركيب والترقية؛ لم يتغير مخططها في عملية التنظيف.

تم توحيد فحص الحساب والجلسة في `Auth::currentUser()`، ونقل عرض خدمات مقدم الخدمة من الكلاس إلى الصفحة، وحذف كود وتنسيقات غير مستخدمة، وترتيب الملفات واستبدال التعليقات القديمة بتعليقات إنجليزية مختصرة عند الحاجة. بقي التصميم والميزات الحالية.

تفاصيل الفحص والنتائج وحدوده في `verification/TEST_REPORT.md` و`verification/results.json`. الفحص استخدم بيانات تجريبية معزولة، وليس قاعدة بياناتك الفعلية.
